WHAT IS THIS WEBSITE?
================================================================================

This is a Risk Assessment Tool - a website that helps organizations identify
and manage cybersecurity risks to protect their information and systems.

Think of it like a "Security Checklist Manager" for your organization.


WHAT DOES IT DO? (In Simple Terms)
================================================================================

Imagine you own a small business with computers, customer data, and a website.
This tool helps you:

1. LIST YOUR VALUABLE THINGS (Assets)
   - Your computers, servers, databases, customer data, etc.
   - Like making an inventory of everything important

2. IDENTIFY DANGERS (Threats & Vulnerabilities)
   - What bad things could happen? (hackers, viruses, data theft)
   - What weaknesses do you have? (old software, weak passwords)

3. CALCULATE HOW RISKY EACH DANGER IS
   - How likely is it to happen?
   - How bad would it be if it happens?
   - The tool automatically calculates: LOW, MEDIUM, HIGH, or CRITICAL risk

4. SEE EVERYTHING IN ONE PLACE (Dashboard)
   - Charts and graphs showing your overall security status
   - Which risks need immediate attention
   - What's improving or getting worse

5. CREATE REPORTS
   - Professional documents you can show to your boss or clients
   - Prove you're following security standards (ISO 27001)

HOW THE WEBSITE WORKS (7 Pages)
================================================================================

PAGE 1: LOGIN
- Enter your email and password to access the system
- Simple and secure

PAGE 2: DASHBOARD (Main Screen)
- See total number of assets (e.g., 48 computers, databases, etc.)
- See total risks identified (e.g., 50 risks found)
- View your overall risk score (e.g., 67/100 - Moderate Risk)
- Beautiful charts showing:
  * Pie chart: How many LOW, MEDIUM, HIGH, CRITICAL risks
  * Bar chart: Risks by category (Technical, Physical, Human)
  * Heat map: Visual grid showing likelihood vs impact
- Recent risks table: Latest security issues found

PAGE 3: ASSET MANAGEMENT
- Add everything valuable to your organization
- For each asset, record:
  * Name (e.g., "Customer Database")
  * Type (System, Data, or Hardware)
  * Value (How important is it? Low/Medium/High/Critical)
  * Who owns it (e.g., "IT Department")
  * Where it is (e.g., "Cloud Server")
- Edit or delete assets as needed
- Search and filter to find specific assets

PAGE 4: THREAT & VULNERABILITY MANAGEMENT
- For each asset, identify dangers:
  * What threat? (e.g., "SQL Injection Attack")
  * What vulnerability? (e.g., "Unsecured database inputs")
  * How likely? (Very Low to Very High)
  * How bad if it happens? (Very Low to Critical)
- The tool automatically calculates the risk level
- See all threats in one table
- Helpful guide explaining what "High Likelihood" means

PAGE 5: RISK ASSESSMENT CALCULATOR
- Choose one of 3 calculation methods:

  METHOD 1 - QUALITATIVE (Simple, uses words)
  - Select: Likelihood = "High"
  - Select: Impact = "High"
  - Result: "HIGH RISK" 🔴
  - Best for: Quick assessments

  METHOD 2 - QUANTITATIVE (Uses money/numbers)
  - Enter: Asset worth $50,000
  - Enter: 75% could be lost if attacked
  - Enter: Happens 2 times per year
  - Result: "Annual Loss = $75,000" 💰
  - Best for: Budget planning, financial analysis

  METHOD 3 - HYBRID (Combines both)
  - Uses words + numbers
  - Includes: How effective are your current protections?
  - Result: Shows residual risk (risk after your protections)
  - Best for: Comprehensive analysis

PAGE 6: REPORTS
- View complete risk register (all risks in one table)
- See TOP 5 HIGHEST RISKS that need immediate attention
- Risk summary statistics:
  * How many Critical risks
  * How many High risks
  * How many Medium risks
  * How many Low risks
- Executive Summary - professional report showing:
  * Key findings
  * Current status
  * Recommendations
  * ISO 27001 compliance info
- Print or export to PDF (for presentations/meetings)

PAGE 7: REGISTER (Sign Up)
- Create your account
- Enter your name, email, organization
- Set password


WHAT IS ISO 27001?
================================================================================

ISO 27001 is an international standard for information security.

Think of it like a "Gold Star" certification that proves your organization:
- Takes security seriously
- Has proper processes in place
- Regularly checks for risks
- Protects customer data properly

Many clients/partners require this certification before working with you.

This tool follows ISO 27001:2022 (latest version) requirements.


HOW IT CALCULATES RISK
================================================================================

Simple Formula:

RISK LEVEL = LIKELIHOOD × IMPACT

Example:
- Likelihood: High (score: 4)
- Impact: High (score: 4)
- Risk = 4 × 4 = 16
- Result: HIGH RISK ⚠️

The tool uses color coding:
🟢 GREEN   = Low Risk (1-5)      → Can wait
🟡 YELLOW  = Medium Risk (6-11)  → Plan to fix
🟠 ORANGE  = High Risk (12-19)   → Fix soon
🔴 RED     = Critical Risk (20+) → Fix NOW!

GETTING STARTED
================================================================================

1. Install Node.js on your computer

2. Open terminal/command prompt

3. Navigate to the project folder:
   cd "web-based Risk Assessment Tool Dashboard System"

4. Install dependencies:
   npm install

5. Start the website:
   npm run dev

6. Open browser to:
   http://localhost:5173

7. Log in with any email/password (it's a demo)

8. Start adding your assets and risks!
